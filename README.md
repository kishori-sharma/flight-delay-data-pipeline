# flight-delay-data-pipeline

A data engineering project focused on processing, transforming, and analyzing flight delay data using Databricks, PySpark, and SQL.

## Project Overview

This project processes flight data through an ETL pipeline to clean, transform, and analyze information related to flight delays, cancellations, airlines, routes, and time-based travel patterns.

## Technologies Used

- Python
- PySpark
- SQL
- Databricks
- Delta Lake
- ETL / Data Transformation

## Key Features

- Ingested and processed flight datasets
- Performed data cleaning and validation
- Transformed raw data using PySpark and SQL
- Analyzed flight delays and cancellations
- Generated airline and route-level insights
- Structured data for analytical reporting

## Pipeline

Raw Data → Data Cleaning → Data Transformation → Analytics

## Key Analysis

- Flight delay patterns
- Airline-wise delays
- Cancellation analysis
- Route-level performance
- Time-based flight trends
